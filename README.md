# 🏢 Sistema de Comunicação entre Portaria e Moradores

🚧 **Projeto em desenvolvimento**

Sistema desenvolvido com o objetivo de facilitar a comunicação entre a portaria e os moradores de um condomínio.

O projeto foi iniciado como uma aplicação backend utilizando Ruby on Rails e uma API para comunicação entre os componentes do sistema.

## 🛠️ Tecnologias utilizadas

* Ruby
* Ruby on Rails
* Docker

## 🎯 Objetivo do projeto

O objetivo do projeto é desenvolver uma solução para comunicação entre a portaria e os moradores, aplicando conceitos de desenvolvimento backend e criação de APIs.

## 📌 Status

O projeto encontra-se em desenvolvimento e algumas funcionalidades ainda estão sendo implementadas.
